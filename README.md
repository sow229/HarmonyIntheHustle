
  # Equil

  This is a code bundle for the Equil mobile app UI. This project was made in relation to the Office of Creative Inquiry at Lehigh University. 

Harmony in the Hustle is a mental wellbeing app built for startup founders. Grounded in faculty-led research on founder burnout and shaped by 20+ interviews with founders, the MVP brings together three core features:

Anonymous founder forum — a safe space to share struggles and advice with peers who get it
Mentorship matching — connects founders with experienced mentors
Habit streaks — builds sustainable routines for rest, focus, and self-care

  https://creativeinquiry.lehigh.edu/impactfellowships/silicon-valley-social-impact-fellowship/rethinking-wellbeing

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  PS: This was mostly made with Cursor, with the intial UI/UX with Figma.
